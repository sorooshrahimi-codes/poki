## راهنمای هر سایت

### Poki: https://developers.poki.com/
- فایل بازی: `*-poki.zip` · تامبنیل‌ها: `images/thumb_1080.jpg` (اصلی)، `thumb_628.jpg`، تامبنیل دوم برای تست A/B · تامبنیل متحرک: `videos/animated_thumbnail_1080.mp4` · ۳ عکس فرم: `screenshots/`
- همه‌ی متن‌ها و جواب‌های فرم در `INFO.md` (شیت کامل ارسال پوکی).
- فرم: Game title = نام بازی · Engine = AI/Claude/ChatGPT · Build = Playable browser build · Released elsewhere = No.

### CrazyGames: https://developer.crazygames.com/
- Submit game → آپلود `*-crazygames.zip` → سه کاور از `images/` (افقی ۱۹۲۰×۱۰۸۰، عمودی ۸۰۰×۱۲۰۰، مربع ۸۰۰×۸۰۰) → ویدیوهای پیش‌نمایش از بسته‌ی media → متن‌ها از `INFO.md`.
- قبل از ارسال، بازی را در پیش‌نمایش/QA خود پنل یک دور اجرا کن (پنل نشان می‌دهد SDK وصل است).
- اندازه‌ی کاور افقی رسمی تأیید شده؛ عمودی و مربع از تجربه‌اند. اگر پنل اندازه‌ی دیگری خواست بگو.

### Playgama: https://developer.playgama.com/
- آپلود `*-playgama.zip` (فایل تنظیمات Playgama داخلش است) → آیکون ۵۱۲ و کاورها از `images/` → ویدیو از media → متن‌ها از `INFO.md`.
- پیشرفت بازیکن در حافظه‌ی خود Playgama ذخیره می‌شود؛ دکمه‌ی اشتراک لینک مخفی است (قانونشان).

### GameDistribution: https://developer.gamedistribution.com/
- **قبل از آپلود:** در پنل بازی را بساز تا **Game ID** بدهد؛ آن را برای من بفرست تا نسخه‌ی نهایی را با همان شناسه بسازم (الان شناسه‌ی موقت داخلش است).
- در تنظیمات بازی **Rewarded ads** را روشن کن. بعد از آپلود، بازی را از داخل پنل باز کن و اولین تبلیغ را کامل ببین (فعال‌سازی SDK).
- تامبنیل‌ها: `images/` (۵۱۲×۳۸۴، ۵۱۲×۵۱۲، ۲۰۰×۱۲۰)؛ بنر از media · متن‌ها از `INFO.md`.
- دکمه‌ی اشتراک لینک مخفی است (طبق قرارداد).

## نکته‌ها
- هیچ ویدیو یا پوستری آدرس سایت ما را ندارد.
- همه‌ی ویدیوها H.264 / yuv420p هستند و روی گوشی و آیفون پخش می‌شوند.
- عددها و ادعاهای متن‌ها همان ویژگی‌های واقعی بازی‌اند؛ آمار ساختگی نیست.
