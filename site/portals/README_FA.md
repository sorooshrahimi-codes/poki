# نسخه‌های آماده برای سایت‌های بعدی (اگر پوکی رد کرد)

> ⚠️ تا جواب پوکی نیامده، **هیچ‌کدام را منتشر نکن**. پوکی بازی‌ای را که جای دیگر منتشر شده معمولاً نمی‌گیرد.
> ترتیب پیشنهادی: ۱) CrazyGames → ۲) Playgama → ۳) GameDistribution

هر بازی (Deep Luck و Critter Vac) برای هر سایت یک پوشه دارد:

```
packages/portals/
  deep-luck/      crazygames/  gamedistribution/  playgama/  videos/
  critter-vac/    crazygames/  gamedistribution/  playgama/  videos/
```

در هر پوشه:
- `<بازی>-<سایت>.zip`: فایل بازی برای آپلود (SDK همان سایت داخلش است)
- `images/`: کاورها و تامبنیل‌ها در اندازه‌های آن سایت
- `INFO.md`: عنوان، توضیح کوتاه، توضیح کامل، کنترل‌ها، دسته‌بندی، تگ‌ها، زبان‌ها (انگلیسی، آماده‌ی کپی در فرم)

ویدیوها مشترک‌اند (`videos/`): یک کلیپ ۱۵ ثانیه‌ای بی‌صدا (برای پیش‌نمایش) و تریلر کامل با صدا.

---

## ① CrazyGames
- **پنل توسعه‌دهنده:** https://developer.crazygames.com/
- **ارسال:** Submit game → آپلود `*-crazygames.zip` → سه کاور (افقی، عمودی، مربع) از `images/` → ویدیوی پیش‌نمایش → متن‌ها از `INFO.md`.
- **داخل بازی:** SDK نسخه‌ی ۳: اعلام شروع/پایان بارگذاری، شروع/توقف بازی، تبلیغ بین بازی‌ها (midgame) و تبلیغ جایزه‌دار. دکمه‌ی «چالش با دوست» با لینک دعوت خود CrazyGames کار می‌کند.
- **قبل از ارسال:** بازی را در «QA Tool» یا Preview خود پنل یک دور تست کن؛ پنل نشان می‌دهد SDK درست وصل شده یا نه.
- **اندازه‌ی کاورها:** افقی ۱۹۲۰×۱۰۸۰ طبق مستندات رسمی تأیید شده. عمودی ۸۰۰×۱۲۰۰ و مربع ۸۰۰×۸۰۰ از روی حافظه ساخته شده‌اند؛ اگر پنل اندازه‌ی دیگری خواست، بگو تا عوضشان کنم.

## ② Playgama
- **پنل توسعه‌دهنده:** https://developer.playgama.com/
- **ارسال:** آپلود `*-playgama.zip` → آیکون و کاور از `images/` → متن‌ها از `INFO.md`. تیمشان بررسی می‌کند و بعد بازی را به پلتفرم‌های شریک (از جمله YouTube Playables) می‌فرستد.
- **داخل بازی:** Playgama Bridge نسخه‌ی ۲: پیام «بازی آماده است»، تبلیغ بین بازی و جایزه‌دار، و **ذخیره‌ی پیشرفت در حافظه‌ی خود Playgama** (طبق قانونشان). فایل `playgama-bridge-config.json` هم کنار index.html هست.
- **دکمه‌ی اشتراک‌گذاری لینک** در این نسخه مخفی است (لینک به بیرون مجاز نیست).
- **اندازه‌ی تصاویر:** صفحه‌ی الزامات رسمی‌شان را نتوانستم بخوانم؛ آیکون ۵۱۲×۵۱۲ و کاور ۱۹۲۰×۱۰۸۰ رایج‌ترین اندازه‌هاست. هر اندازه‌ی دیگری خواستند، می‌سازم.

## ③ GameDistribution
- **پنل توسعه‌دهنده:** https://developer.gamedistribution.com/
- **یک قدم لازم قبل از آپلود:** در پنل یک بازی جدید بساز تا **Game ID** بدهد. این شناسه باید داخل بازی باشد؛ آن را برای من بفرست تا نسخه‌ی نهایی را با همان شناسه بسازم (الان جایش `REPLACE_WITH_GD_GAME_ID` است).
- **در تنظیمات بازی در پنل:** گزینه‌ی **Rewarded ads** را روشن کن، وگرنه تبلیغ جایزه‌دار درخواست نمی‌شود.
- **فعال‌سازی:** بعد از آپلود، بازی را از داخل پنل باز کن و تبلیغ اول (pre-roll) را کامل ببین؛ این کار اتصال SDK را فعال می‌کند.
- **داخل بازی:** SDK رسمی GD: هنگام تبلیغ بازی می‌ایستد و صدا قطع می‌شود، تبلیغ بین بازی و جایزه‌دار (جایزه فقط وقتی تبلیغ تا آخر دیده شود).
- **دکمه‌ی اشتراک‌گذاری لینک** در این نسخه مخفی است (طبق قرارداد، لینک به بیرون مجاز نیست).
- **اندازه‌ی تامبنیل‌ها:** ۵۱۲×۳۸۴، ۵۱۲×۵۱۲ و ۲۰۰×۱۲۰ رایج‌ترین اندازه‌های GD هستند ولی در مستندات رسمی پیدایشان نکردم.

## ساختن دوباره‌ی نسخه‌ها (برای من / برنامه‌نویس)
در پوشه‌ی هر بازی (`game/` = Deep Luck، `critter/` = Critter Vac):
```
npm run build:crazygames        → dist-crazygames/
npm run build:playgama          → dist-playgama/
GD_GAME_ID=xxxx npm run build:gamedistribution → dist-gamedistribution/
npm run build                   → dist/ (نسخه‌ی پوکی، بدون تغییر)
```
همه‌ی کد مربوط به سایت‌ها در یک فایل است: `src/platform/poki.ts`؛ بقیه‌ی بازی برای همه‌ی سایت‌ها یکی است.

## چک فنی انجام‌شده
هر ۶ نسخه (۲ بازی × ۳ سایت) در مرورگر بدون خطا از طرف کد بازی بالا آمدند و هرکدام فقط SDK خود آن سایت را بارگذاری کردند. نمایش واقعی تبلیغ فقط داخل پنل خود هر سایت قابل تست است.
